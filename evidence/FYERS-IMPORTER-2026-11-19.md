# FYERS offline importer evidence — 2026-11-19

**Scope:** offline import of completed FYERS SDK capture sessions. The Python
SDK recorder remains the capture authority; no live bridge, IPC service,
entitlement verification, canonical event projection or trading is included.

## Contract

- Manifest checks: provider `FYERS`, declared chain validity, no writer error,
  capture-session (not provider) sequence, journal filename, SHA-256 of exact
  journal bytes, record count and head hash.
- Chain checks: recompute each record hash from the previous head plus the
  canonical JSON of the record without `record_hash`; any mismatch fails closed.
- Record accounting: every verified record becomes one raw-journal frame via
  `DurableIngestor` with `SequencePolicy::CaptureSession`.
- Byte fidelity: `event_type`, `payload` and `capture_sequence` are preserved
  through an explicit canonical JSON re-encoding; the original Python journal
  remains the authoritative capture artifact. Gap records are retained.
- Idempotence: a session marker derived from `run_id` is embedded in each frame.
  A streaming scan finds the highest committed capture sequence for that
  session; a complete repeat import is a no-op, while an interrupted import
  resumes at the next record instead of silently dropping the tail. Delivery
  identity is scoped by session id, so two sessions with overlapping local
  sequences share one journal without collisions.

## Tests

Fixture `apps/fyers-importer/tests/fixtures/session/` is generated by
`tests/generate_fixture.py` using the real Python `HashChainJournal`.

- `verifies_a_real_python_hash_chain_session`: manifest plus four records,
  including a gap record.
- `tampered_manifest_or_chain_fails_closed`: bad digest and broken chain are
  refused before any write.
- `import_is_byte_faithful_and_idempotent`: four frames imported, event type
  and gap metadata preserved, repeat import adds nothing.
- `interrupted_import_resumes_without_dropping_records`: a journal truncated
  after two frames resumes and reaches all four records.
- `two_sessions_with_overlapping_local_sequences_share_the_journal`: two
  sessions with the same local sequences produce eight records.

## Limits

The SDK supplies decoded callback JSON, not original WebSocket bytes; the
manifest says so, and the importer does not claim wire-level fidelity. No
provider sequence is available, so continuity is session-scoped only. Rust
and Python number formatting can differ for extreme float spellings; the
fixture uses ordinary decimal literals and any such divergence fails closed
rather than importing unverified bytes.
