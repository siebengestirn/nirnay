# M2.3 — deterministic Rust strategy runtime — 2026-11-20

**Objective:** first strategy-runtime increment under signed M2 authorization.
Baseline `f0b9b7d007318f601fb29f80e63458c579afc3ac`. Python remains the research
environment; the Rust runtime executes only frozen, validated artifacts.

## What was implemented

- New `crates/strategy-runtime` (engines layer): `FrozenArtifact` loads and gates
  a v1 artifact by status (`validated` or `approved_for_paper` only), requires
  non-empty experiment lineage, complete validation fields and a supported
  rule. Research `candidate`, `rejected` and `retired` artifacts are refused.
  The exact artifact bytes are hashed at load time.
- `Strategy` is a narrow interface producing intents only. `StrategyEvent`
  exposes market observations and caller context; it carries no account, cash,
  broker, OMS, order or risk state.
- `RationalEmaCross` uses exact `i128` rationals with normalized state, explicit
  half-away-from-zero rounding and a strict monotonic observation fence. No
  floating point in strategy state.
- Golden vectors are generated by a Python `fractions.Fraction` reference with
  the identical rule (`tests/generate_golden.py`) and checked in. Exact parity
  is asserted by a Rust test. This is parity for a precisely defined rational
  contract, not a claim about Python's `Decimal` EMA.

## Tests

Eight tests: eligible frozen artifact, candidate refusal, missing-lineage
refusal, golden-vector parity with emitted intents, non-monotonic observation
refusal, a structural check of the narrow event surface, rejection of a
struct-literal artifact that bypasses `load()`, and a check that the committed
generator is executable and reproduces the golden vector byte for byte.
Runtime gating is enforced in both `FrozenArtifact::load` and
`RationalEmaCross::from_artifact`, so an ungated struct literal cannot construct
an executable strategy. No live or shadow execution.

## Verification

`cargo test -p strategy-runtime` — 8 passed; Clippy `-D warnings` clean;
`cargo xtask check` PASS; `make check` exit 0; all style gates PASS. Hosted
exact-head CI is recorded by the PR.

## Boundaries and non-claims

- Systems fixture, not validated alpha. No experiment registration, search,
  walk-forward or cost validation is implemented here; the frozen artifact's
  validation fields are consumed as contract text, not recomputed.
- No order submission, OMS, portfolio, risk authority, broker adapter, account
  state or live routing. Intents are produced and returned to the caller only.
- No Python authority change, no new dependency source, no infrastructure.
- No real market data; golden inputs are synthetic. Shadow execution and
  source-to-paper certification remain later stages.
- R5/R6 live promotion remains separately authorized and unexercised.
